# Step through the changes

- Yellow cells changed. The old value is struck through next to the new one.
- Green rows were added, red rows were removed. Rows that were inserted do not shift the rest of the sheet: they are found and lined up.
- A column added in the middle is found by its header, so the cells next to it are not marked.
- Next and Previous (or the N and P keys) jump from change to change, also across sheets.
- Values compares what the cells show. Formulas compares the formulas, so a changed formula with the same result shows up.
- Click a cell to see its old and new value in full, and copy them.

Each sheet tab shows how many rows differ. Sheets that exist in only one file are marked added or removed.
