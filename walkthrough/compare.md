# Compare two files

Select two files in the Explorer (Cmd+click or Ctrl+click), right-click one of them and pick Compare Selected Excel Files. The first file you selected is the older one.

With one file selected, pick Compare with... and choose the second file in the dialog. The command palette has Excel Compare: Compare Two Excel or CSV Files... too.

The two files can have different types: an .xlsx export can be compared with the .csv that came before it.

Supported: .xlsx, .xlsm, .xls, .ods, .csv and .tsv.
